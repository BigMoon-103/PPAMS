Introduction

In today's academic and professional environments, many spend extended periods seated, gradually developing poor posture without being consciously aware of it. Our P.P.A.M.S addresses this common problem by combining comfort, technology, and smart feedback. It transforms any ordinary chair into a posture aware system that helps users develop healthier sitting habits through continuous observation and simple feedback mechanisms.

Project Objective

The primary goal of this project is to create an embedded sensing and feedback system that monitors seated posture and provides corrective feedback during prolonged sitting. By tracking pressure points along the spine and shoulders, the system identifies unhealthy positions and encourages regular movement through alerts. Rather than attempting to diagnose medical conditions, it focuses on posture awareness and behavioral correction, ultimately reducing long term strain while promoting more mindful sitting behavior.

Abstract

This project presents the Posture Pillow Attachment Monitoring System (P.P.A.M.S.), an embedded sensing and feedback system designed to address poor sitting posture in academic and professional environments. The system utilizes pressure sensors embedded in a removable chair attachment to monitor body position and detect posture deviations. A microcontroller processes sensor data, compares it against personalized calibration baselines, and activates vibration and audio feedback when sustained poor posture is detected. The system is powered by a rechargeable battery and complemented by a mobile application for calibration and monitoring. Testing validates the system's ability to detect common posture problems and encourage corrective behavior without disrupting user activities.

Introduction

Prolonged sitting has become a defining characteristic of modern work and study environments. While necessary for many activities, extended sitting sessions often lead to poor posture development, causing muscle strain, spinal misalignment, and long term health issues. Many individuals are unaware of their posture degradation until discomfort or pain becomes significant.

Traditional solutions include ergonomic furniture, which is expensive and nonportable, or periodic reminders, which lack awareness of actual posture quality. The P.P.A.M.S. project addresses these limitations by creating a portable system that provides real-time posture awareness through sensor-based detection and immediate feedback.

This project focuses on behavioral correction rather than medical diagnosis. By making users aware of their posture deviations as they occur, the system encourages development of healthier sitting habits. The design emphasizes nonintrusive feedback that prompts correction without disrupting concentration or workflow.

System Design & Architecture

The P.P.A.M.S. architecture consists of four primary subsystems: sensing layer, processing unit, feedback mechanisms, and power management. The sensing layer employs an array of pressure sensors strategically positioned in a back pillow and seat drape. These sensors detect pressure distribution patterns that correlate with body position and posture quality.

The processing unit is built around a microcontroller that continuously reads sensor values, performs signal filtering to remove noise and transient variations, and compares current readings against calibrated baselines. The calibration process occurs during initial use, where the user sits in their preferred correct posture while the system records sensor values as reference points.

During operation, the system calculates deviation metrics by comparing live sensor data against baselines. Short-term variations are ignored to prevent false alerts from normal movements. Only sustained deviations exceeding threshold values trigger feedback activation. This approach balances sensitivity with practical usability.

Feedback is delivered through vibration motors embedded in the back pillow and an audio buzzer. The combination provides both tactile and auditory cues that are noticeable but not disruptive. Power is supplied by a rechargeable lithium battery with sufficient capacity for full-day operation. Power management circuits optimize consumption to extend battery life.

Implementation

Hardware implementation began with sensor selection and testing. Pressure sensors were evaluated for sensitivity, response time, and durability. Selected sensors were integrated into fabric substrates that form the pillow and drape components. Wiring was routed to minimize interference with comfort while maintaining reliable electrical connections.

The microcontroller firmware implements several key functions: analog-to-digital conversion of sensor signals, digital filtering using moving average algorithms, baseline storage and comparison, deviation threshold detection, and feedback control. The code is structured in modular fashion to facilitate testing and future modifications.

Calibration logic records multiple sensor readings over a brief period and stores average values as baselines. During normal operation, a sliding window approach evaluates recent sensor history to distinguish sustained deviations from momentary movements. Threshold values were empirically determined through testing with multiple users and posture scenarios.

The mobile application was developed using a cross-platform framework to support both iOS and Android devices. The app communicates with the hardware via Bluetooth, providing interfaces for calibration initiation, real-time status display, and historical data visualization. User testing guided interface design to ensure clarity and ease of use.

Conclusion & Future Work

The P.P.A.M.S. project successfully demonstrates a practical approach to posture awareness and behavioral correction through embedded sensing and feedback. The system achieves its primary objectives of detecting poor posture, providing immediate feedback, and encouraging healthier sitting habits in a portable package.

Key achievements include personalized calibration that adapts to individual users, reliable detection of common posture problems, nonintrusive feedback that integrates into normal activities, and modular design that supports maintenance and upgrades. The project validates the effectiveness of sensor-based posture monitoring as a behavioral correction tool.

Current limitations include sensor coverage that may not detect all posture variations, dependency on initial calibration quality, and lack of long term posture trend analysis. Future enhancements could include machine learning algorithms for improved detection accuracy, expanded sensor arrays for more comprehensive coverage, integration with productivity and health tracking platforms, and adaptive feedback that adjusts based on user response patterns.

This project contributes to the growing field of embedded health monitoring systems and demonstrates how relatively simple technology can address real world problems. The principles and techniques developed here have potential applications in other behavioral monitoring and correction scenarios beyond posture management.
